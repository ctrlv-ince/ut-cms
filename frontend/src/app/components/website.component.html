ESP32 BH1750 Light Sensor Sketch & Integration

C++ edge firmware engineered by David, Lance B. for ESP32. Acquires real-time physical telemetry from Ultrasonic (HC-SR04), Soil Moisture, and a BH1750 light sensor. The BH1750 sketch reads illuminance over I²C and reports each reading in lux over Serial.

Topic: esp32/sensor_data
Interval: 5,000 ms • QoS 1
LWT: esp32/status
Retained "online" / "offline"
Pins: GPIO 25 (Trig) / 26 (Echo)
📡

Ultrasonic Sensor (HC-SR04)

Emits 10µs ultrasonic bursts; measures echo return duration to compute accurate distance with a 30,000µs timeout guard.

Telemetry Metric
distance_cm
Continuous high-resolution mode; readings reported in lux.
Type: Pulse Timing Active
Pin: ADC1 - GPIO 34 (Wi-Fi Safe)
🌱

Soil Moisture Sensor

12-bit ADC reading calibrated against dry air (3000) and saturated soil (1200) to output percentage saturation.

Telemetry Metrics
soil_percent & soil_raw
Range: 0% – 100% Saturation
Channel: ADC1_CH6 Calibrated
I²C: SDA GPIO 21 / SCL GPIO 22
💧

BH1750 Light Sensor

Measures ambient illuminance in lux using the BH1750 digital sensor over I²C.

Telemetry Metrics
light_lux
Continuous high-resolution mode; readings reported in lux.
I²C address: 0x23 (default) Digital

MQTT Payload Schema: Topic esp32/sensor_data

Example integration payload for a Node-RED flow. The standalone BH1750 sketch above reports readings over Serial.

Serialized Packet ~148 bytes 
{
  "distance_cm": 18.42,
  "soil_raw": 1840,
  "soil_percent": 64,
  "light_lux": 352.00,
  "rssi": -58
}
Null Handling: distance_cm: null if no echo
Field Key Type Source Sensor & Meaning Node-RED Processing
distance_cm Float | null Distance in cm measured by HC-SR04 ultrasonic echo timing. Threshold alerts, gauge chart widget
soil_raw Integer (0-4095) Raw 12-bit ADC reading on Pin 34. Dry ≈ 3000, Wet ≈ 1200. Calibration logging
soil_percent Integer (0-100) Normalized soil moisture saturation percentage. Irrigation logic switch & line chart
light_lux Float (lux) Ambient illuminance measured by the BH1750 over I²C. Light intensity gauge and history chart
rssi Integer (dBm) Wi-Fi received signal strength indicator. Wireless link health monitor

ESP32 Pinout & Peripheral Wiring Map

Hardware pin assignment designed by David, Lance B. BH1750 uses I²C on GPIO 21 and GPIO 22.

Peripheral ESP32 Pin Signal Type Operating Voltage
HC-SR04 Trigger GPIO 25 Digital Output (10µs pulse) 3.3V
HC-SR04 Echo GPIO 26 Digital Input (pulseIn) 3.3V (divider)
Soil Moisture Sensor GPIO 34 (ADC1_CH6) Analog Input (12-bit ADC) 3.3V
BH1750 SDA GPIO 21 I²C Data 3.3V
BH1750 SCL GPIO 22 I²C Clock 3.3V
Power Supply Rail 3V3 & GND Common Ground & VCC 3.3V DC
Critical ESP32 Hardware Design Decisions

1. BH1750 I²C Wiring: Connect BH1750 SDA to GPIO 21 and SCL to GPIO 22; connect VCC to 3.3V and GND to GND.

2. Non-Blocking Loop: The sketch checks the BH1750 every second and prints its reading in lux over Serial.

3. I²C Address: The BH1750 commonly uses I²C address 0x23; some modules can use 0x5C.
